# Source publication boundary

Included: independently maintained collection/integration sources, preparation tools, metadata and fingerprints, tests, project-written documentation, notices, selected fan artwork and documentation screenshots.

Excluded: original discs and BIOS, extracted assets, translated/generated game and BIOS C, game executables, overlay DLLs/caches, original SDK/toolchain binaries, memory cards, runtime states, RAM/VRAM/audio dumps, bulk traces and private build receipts. The private 1.47 GB owner-test ZIP is not a public release asset. Removing its disc files alone would still leave translated game/BIOS code.

The two raw instruction/payload locations deliberately withheld from this snapshot are collection/runtime/palette_native_source_catalog.json and collection/runtime/jf1_family_sources/. Generation recipes must replace them before a clean public build is advertised.

Existing address/size/hash metadata is retained to describe supported revisions and guarded hooks. This is a technical exclusion check, not a legal clearance opinion. Screenshots are documentation of gameplay, not a license to reuse game assets. Fan character artwork does not grant rights to the original characters.

Component licenses remain separate. The included PSXRecomp license is PolyForm Noncommercial; keep its required notices and review its permitted-use terms. Do not label the entire combined project MIT or advertise commercial rights. Translation patch redistribution and any further upstream/license obligations must be reviewed for the exact eventual binary package.

Publish from this isolated source export, not the development workspace or its old Git history. Adding a .gitignore does not remove material already committed to history. A future playable public release needs a user-input generation/build workflow and a fresh payload/license audit.
